# <a name="turkish"></a>Commerce ISARUD - E-Ticaret Çözümü

WordPress için gelişmiş bir e-ticaret çözümüdür ve çevrimiçi işletme yönetimi için eksiksiz bir araç seti sunar.

## 🚀 Özellikler

### Ürün Yönetimi
* Sınırsız ürün ekleme
* Gelişmiş ürün varyasyonları
* Dijital ve indirilebilir ürünler
* Ürün kategorileri ve etiketleri
* Toplu ürün yönetimi
* Stok takibi
* Stok kodu ve barkod desteği

### Sipariş Yönetimi
* Gelişmiş sipariş işleme
* Sipariş durumu takibi
* Sipariş notları ve geçmişi
* Fatura oluşturma
* İrsaliye oluşturma
* Toplu sipariş yönetimi

### 💳 Ödeme Sistemleri
* PayTR entegrasyonu
* iyzico entegrasyonu
* Kapıda ödeme
* Banka havalesi
* Banka entegrasyonları
  * Garanti
  * İş Bankası
  * Yapı Kredi
  * Akbank
* EST ve Posnet sanal POS desteği

### 🚚 Kargo Entegrasyonları
* Yurtiçi Kargo
* MNG Kargo
* UPS
* Gelişmiş kargo bölgeleri
* Kargo takip sistemi
* Çoklu kargo yöntemleri

### 📊 Vergi Yönetimi
* Otomatik KDV hesaplamaları
* Vergi raporlama sistemi
* Fatura oluşturma
* Bölgesel vergi ayarları
* Vergi sınıfı yönetimi

### 📈 Raporlama Sistemi
* Satış raporları
* Stok raporları
* Müşteri analizleri
* Vergi raporları
* Excel/PDF/CSV dışa aktarım

### 🔌 API ve Entegrasyonlar
* REST API uç noktaları
* Webhook sistemi
* ERP entegrasyonları (Logo, Nebim)
* Muhasebe yazılımları (Paraşüt, QuickBooks)
* Pazar yeri entegrasyonları
  * n11
  * Trendyol
  * Hepsiburada

## ⚙️ Kurulum

1. Eklenti dosyalarını `/wp-content/plugins/com-isarud` dizinine yükleyin
2. Eklentiyi WordPress'in 'Eklentiler' ekranından etkinleştirin
3. Commerce ISARUD menüsünden ayarları yapılandırın
4. Ödeme ve kargo yöntemlerini ayarlayın
5. Ürün eklemeye başlayın

## 📋 Gereksinimler

* WordPress 5.8 veya üzeri
* PHP 7.4 veya üzeri
* MySQL 5.6 veya üzeri

## 🔧 Geliştirici Bilgileri

* Modüler mimari

* Özelleştirilebilir şablonlar
* Genişletilebilir yapı

### Product Management

* Product categories and tags
* Bulk product management
* Inventory tracking
* SKU and barcode support

### Order Management

* Order notes and history
* Invoice generation

* Bulk order management

  * Trendyol

## ⚙️ Installation

1. Upload plugin files to `/wp-content/plugins/com-isarud` directory
2. Activate the plugin through WordPress 'Plugins' screen
3. Configure settings from Commerce ISARUD menu
4. Set up payment and shipping methods
5. Start adding products

## 📋 Requirements

* WordPress 5.8 or higher
* PHP 7.4 or higher
* MySQL 5.6 or higher
